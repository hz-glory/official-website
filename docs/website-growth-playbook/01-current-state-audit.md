## 3. 内容质量

### 中文
- **优点**：定位句锋利；痛点不过度贩卖焦虑；FDE 与成长模型完整。
- **缺点**：抽象词偏多（闭环、产品化抽象、经营指标、中台）；部分像内部战略备忘录。

### 英文
- **优点**：与中文结构对齐；部分表达生动（ships and leaves / demo theater）。
- **缺点**：直译痕迹（Capability system、product abstraction）；投资人口径与客户口径混排。

### 一致性
- FDE、指标驱动、双主线行业排序：一致。
- 「投资合作」有 CTA，无材料页：不一致。
- Insights 在导航但无内容：不一致。

## 4. 设计与体验

### 符合品牌指南的部分
- 背景 `#f9f7f4`、暖橙 `#d9772c`、青绿 `#2f6f6a`
- 标题衬线 + 正文无衬线
- 留白充足，卡片轻边框轻阴影
- 避免紫蓝赛博与 AI 陈词滥调插画

### 体验问题
| 问题 | 位置 | 影响 |
|---|---|---|
| 主导航 7 项 + CTA，密度高 | Header | 平板易拥挤；弱项被抬成主入口 |
| Insights 占位仍上导航 | Header / Insights | 损害专业感 |
| Reveal 默认 opacity:0 | `Reveal.tsx` + CSS | JS 失败时内容不可见；无 reduced-motion |
| 图库图非实拍 | `public/images/*` | 「模板站」感 |
| 团队仅字首头像 | About | 信任不足 |
| 子页无统一尾 CTA | 多数内页 | 看完即走 |
| 联系信息只有「杭州」 | Contact / Footer | 降低可达性 |
| `html lang` 固定 zh | `layout.tsx` | 英文 SEO/可访问性受损 |

## 8. 审计结论

官网 **结构分高、转化分低、证据分中低**。  
下一步不是「再加更多介绍段落」，而是：

1. 让行动发生（表单/CTA）
2. 让证据可见（案例/团队/流程）
3. 让内容可被发现（SEO/Insights）
4. 让三类受众各走各路（分流着陆）
