# 02 · 受众吸引力诊断

官网同时服务三类人：**潜在客户、投资人、候选人**。当前内容「通吃」导致三类都「看得懂，但动不了」。

---

## A. 潜在客户（制造业 / 政企 / 跨境与流程自动化买家）

### 他们落地后 10 秒在问什么
1. 你们跟普通外包/集成商有何不同？
2. 有没有和我类似的做过？
3. 怎么开始？要投入什么？多久看到结果？
4. 出了事谁负责？数据安不安全？

### 官网现在答得如何

| 问题 | 现状 | 缺口 |
|---|---|---|
| 差异化 | ✅ FDE 讲清楚了 | 缺「首月做什么」的具体画面 |
| 同类案例 | 🟡 有行业对应案例 | 量化与证言不足；匿名过多 |
| 怎么开始 | 🟡 有「预约诊断」 | 诊断是什么、多久、产出物未说明 |
| 责任与安全 | ❌ 几乎没有 | 缺交付纪律、隐私、驻场协作方式 |

### 吸引力评分：**5.5 / 10**

### 提升杠杆（按影响排序）
1. **案例页变成「销售武器」**：每个案例补「适用谁 / 周期 / 关键指标 / 下一步 CTA」
2. **诊断产品化**：把「预约诊断」写成有边界的服务（时长、参与角色、交付物）
3. **解决方案页加 CTA + 适用客户反例**（谁不适合），反而更可信
4. **企业信任区**：驻场方式、里程碑门禁、数据与权限原则（不谈内部合作路径）
5. **行业着陆**：制造/政企各自一屏「场景→能力→案例→预约」

### 客户侧成功信号
- 表单里出现可跟进的项目描述，而不只是「咨询一下」
- 销售回访时客户能复述 FDE 差异（说明叙事生效）

## B. 投资人 / 战略合作方

### 他们落地后 10 秒在问什么
1. 这是人力外包还是能沉淀资产的公司？
2. 有没有可复制的产品化路径？
3. 团队能否打深、能否扩张？
4. 现在处在什么阶段？如何合作？

### 官网现在答得如何

| 问题 | 现状 | 缺口 |
|---|---|---|
| 模式想象力 | ✅ 三阶段成长模型 | 缺真实阶段案例的「资产化」证据链 |
| 产品化 | 🟡 跨境案例标阶段二 | 无产品名/形态/边界说明 |
| 团队 | 🟡 大厂履历 | 无照片、无创始人故事深度、无可验证链接 |
| 阶段与合作 | 🟡 CTA「投资合作」 | 无材料包、无 traction 摘要、表单不通 |

### 吸引力评分：**5.0 / 10**

### 原则（与已确认口径一致）
- 不做融资硬广，不展示具体融资金额/估值
- 表达「开放探讨战略绑定 / 财务投资 / 股权合作」即可

### 提升杠杆
1. 首页成长范式旁挂 **1 个「阶段标注」案例**（已有跨境，强化展示）
2. About 或独立锚点增加 **「合作与开放态度」** 轻量区块（非 IR 页）
3. 投资意向表单字段区分：机构类型、关注点、是否要材料
4. 后续可提供「一页纸」下载（需业务提供数字口径后再做）

## C. 候选人（FDE / AI 应用 / 顾问）

### 他们落地后 10 秒在问什么
1. 真的驻场吗？强度如何？
2. 能学到什么？和大厂/乙方有何不同？
3. 岗位要求是否匹配？
4. 怎么投？多久有回复？

### 官网现在答得如何

| 问题 | 现状 | 缺口 |
|---|---|---|
| 工作方式 | 🟡 有文化描述 | 缺「一周时间分配」具象 |
| 成长 | 🟡 提技术委员会/学习体系 | 缺具体机制展示 |
| JD | 🔴 仅标题/类型/地点 | 无职责、要求、加分项 |
| 投递 | 🔴 跳转联系表单且不通 | 无简历通道、无 SLA |

### 吸引力评分：**4.5 / 10**

### 提升杠杆
1. 每个岗位补全 JD 模板（见规格文档）
2. 「FDE 一天/一周」短模块
3. 投递字段：岗位 + 简历链接/附件说明 + 城市意向
4. 团队页照片上线后，候选人信任显著提升

## D. 三类受众的页面权重建议

| 页面 | 客户 | 投资人 | 候选人 |
|---|---|---|---|
| 首页 | ★★★★★ | ★★★★ | ★★★ |
| 解决方案 | ★★★★★ | ★★ | ★ |
| 行业 | ★★★★★ | ★★ | ★ |
| 案例 | ★★★★★ | ★★★★ | ★★ |
| 关于/方法论 | ★★★★ | ★★★★ | ★★★ |
| 洞察 | ★★★★ | ★★★ | ★★ |
| 招聘 | ★ | ★ | ★★★★★ |
| 联系 | ★★★★★ | ★★★★★ | ★★★★ |

**不要做三个独立官网**；用 **同一站点 + 分意图 CTA + 表单意图字段** 完成分流（与大纲「通用版」策略一致）。

## E. 竞争参照（叙事层面，非抄袭）

| 参照 | 可学 | 不要学 |
|---|---|---|
| Palantir FDE 叙事 | 现场工程师、结果导向 | 过度神秘/好战文风 |
| 顶级数字化咨询站 | 行业页深、案例证据 | 堆砌框架图与空洞愿景 |
| 优秀服务型 AI 公司 | 把「诊断」产品化 | AI 紫光粒子与机器人手 |

光荣智能的差异化应继续压在：**现场共建 + 指标里程碑 + 项目验证后可产品化**，而不是「我们也做大模型应用」。
