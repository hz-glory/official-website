## 2. 核心判断

### 已经做对的事
1. **定位一句说清楚**：不是卖软件的乙方，而是 FDE 现场共建、对经营指标负责。
2. **主线清晰**：智能制造 + 政企数字化置顶，跨境合规作为项目→产品实证。
3. **双语同步**：中英不是后置翻译页，结构对齐。
4. **视觉方向正确**：暖白 + 暖橙/青绿，避免了常见「AI 紫蓝赛博脸」。
5. **部署底座完成**：双云上线，可并行迭代。

### 最大短板（决定「像不像真公司阵地」）
1. **转化链路未闭环**：联系表单只做前端假成功，线索为零。
2. **信任证据不够硬**：案例匿名偏多、量化不足、无客户证言/Logo、团队无照片。
3. **内容阵地空转**：Insights 是「即将发布」，却挂在主导航，损害可信度。
4. **受众分流不够**：客户 / 投资人 / 候选人共用同一套「介绍」，缺少分诉求着陆体验。
5. **可发现性弱**：搜索引擎与社交媒体分享几乎没有技术基建。

## 3. 「成为公司宣传阵地」的定义（建议作为 OKR）

官网要同时完成四件事：

1. **解释**：30 秒内让访客理解「你们跟外包/SaaS 有什么不同」。
2. **证明**：用案例、团队、流程、成果让人相信「你们做过、能做成」。
3. **分流**：客户预约诊断、投资人留资、候选人投递，三条路径各自顺畅。
4. **沉淀**：洞察与资料持续产出，成为长期内容资产，而不是一次性上线。

达到以下状态可视为「真正成为阵地」：

- 表单提交成功率 > 95%，线索进入可跟进渠道（邮箱/飞书/CRM）
- 首页首屏跳出后仍有 ≥2 个明确行动入口被点击
- 至少 2 个案例具备可对外的量化结果 + 阶段标注
- Insights 至少 3 篇真实文章上线，导航不再「空壳」
- 搜索分享带 OG 图与正确双语标题；sitemap 可抓取全站

## 4. 决策建议

### 立即做（P0，不依赖大量新素材）
- 接通联系表单后端
- 隐藏或标记 Insights，直到有真内容
- 全站关键页补「预约诊断 / 同类项目咨询」CTA
- 补 SEO 基础件（sitemap、robots、metadata、OG）
- 加基础分析（页面浏览 + CTA + 表单提交）

### 需要业务侧补料后才能做好（P1）
- 团队照片与更完整履历对外口径
- 案例量化指标与（若可）客户证言
- 对外邮箱 / 微信 / 完整联系信息
- 1 份可下载的公司介绍 PDF 或一页纸

### 可并行规划（P2–P3）
- 洞察内容飞轮
- 行业深页与解决方案商品化包装
- 招聘 JD 与投递流程
- 轻量增长实验（Hero CTA 文案、案例排序）

## 5. 风险提示

| 风险 | 影响 | 缓解 |
|---|---|---|
| 继续对外推空壳 Insights | 专业感下降 | 导航隐藏或改「即将上线」落地页 |
| 表单假成功被客户感知 | 信任崩塌 | P0 必须先修 |
| 过度使用内部术语（主线/产品化抽象） | 客户听不懂 | 见 `09-messaging-kit.md` |
| 案例披露口径不一致 | 合规/客户关系风险 | 每个案例锁定披露级别再改文案 |
| 图库图过多 | 「像模板站」 | 逐步替换为现场/团队真实影像 |
